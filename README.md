# Controle de Devoluções — J&T

Sistema operacional com **sincronização em tempo real** (Firebase).

## Usar online

https://anderson390285.github.io/controle-devolucoes/

> Se a página não abrir: repositório → **Settings → Pages** → Source: **main** / **(root)** → Save

## Como funciona

1. Você e a outra pessoa abrem o **mesmo link**
2. Qualquer cadastro, exclusão ou “+ Ausência” aparece para os dois em poucos segundos
3. O status no topo fica **verde**: “Sincronizado com a nuvem”
